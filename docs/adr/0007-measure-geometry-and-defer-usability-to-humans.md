# 自动测量几何误差，模型可用性由人类判断

Status: accepted（2026-09-21）；supersedes
[ADR-0004](0004-use-curated-cross-backend-golden-baselines.md) 中以数值公差自动
裁决几何适用性的规则。该 ADR 的来源治理、摘要和人工更新原则继续适用。

用户已在 win11 检查 6 组 CATIA / FreeCAD 模型，表示肉眼看不出区别，并认为
这些误差在当前建模与实际计算中可忽略。用户进一步明确长期规则：以后只测量
模型并形成标准误差报告，实际是否可用一律由人类判断。

## 决策

- 自动化负责输入、单位、文件身份、有效闭合单实体、重开、依赖与进程生命周期
  等运行完整性检查；这些检查完成不等于模型适用性获批。
- 对输入保持、导引保持、连续性、原生/STEP 交换及跨后端几何差异只报告数值和
  测量覆盖，不因超过误差阈值而输出模型合格/不合格，也不据此拒绝交付模型。
  求解器自身的拟合/重参数化参数仍然是算法参数，不因此删除或擅自改动。
- 标准报告记录输入与制品 SHA-256、算法/环境、单位、采样方法、双向 max/RMS、
  体积/质心/包围盒、逐站位完整性及重试信息。有限样本与默认积分的局限必须
  显式说明；截面提取缺口不能通过删站位隐藏。
- 运行失败、无效数值、缺失记录、身份不符或进程泄漏可以使自动检查失败。
  几何偏差大小和测量缺口本身供人类解释，报告不自动继承历史模型的批准。
- 人工结论单独保存日期、用途、检查包/制品摘要和原话或忠实摘要，不能从“误差
  很小”推导未来模型的批准。本次 6 组结论见
  [人工检查记录](../validation/golden-matrix-2026-09-21.md#人工检查结论)。
- 既有阈值转为历史测量背景；本次迁移是用户明确改变验收策略，不是调大阈值
  以制造通过。公开参考夹具仍须有独立的来源、再分发依据和人工基线批准。

## Consequences

Linux CAD CI 产出供人工判断的报告和模型，初期 non-blocking。之后即便把
环境与报告完整性检查设为 required，也只能表示测量工作正常完成，不能表示
工程可用性。发布仍需工程责任人针对实际制品作明确人工决定。
