# 精度优先路线：Gordon 原型实测（2026-09-08）

结论：Gordon 曲面网络可以显著改善旧原型的叶根后缘走向，并生成有效闭合
单实体；但翼型切换区仍存在约 0.330 mm 的 CATIA 对照采样差异，尚未通过
阶段 2。此结果支持继续评估受约束曲面路线，不代表已选定生产算法。

用户明确允许其他建模方案，决策见 [ADR-0005](../adr/0005-prioritize-geometric-accuracy.md)。
用户目前不知道合适工程公差，因此本记录所有数值均为测量或求解参数，不是
制造公差、工程验收批准或黄金基线批准。

## 原型来源和执行

- 环境沿用 Flatpak FreeCAD 1.1.3；每次运行使用本次目录内独立 user/system 配置。
- 使用 [CurvesWB](https://github.com/tomate44/CurvesWB) 的 Gordon 算法，固定
  commit `e4972f761d126901d13b3a72be64eb14f7d51c92`，下载到本机隔离原型目录，
  未安装进用户 FreeCAD 配置，也未增加产品依赖。
- 入口 `InterpolateCurveNetwork` 来自 CurvesWB 对 DLR TiGL 算法的 Python 移植。
  对照源码保留原许可文件与版权头；Gordon/BSplineAlgorithms 为 Apache-2.0，
  部分辅助模块为 LGPL-2.1-or-later，不能推定整个工作台都是同一许可证。
- 输入使用原 89 截面 FCStd 的 upper/lower 曲线与前后缘参考曲线；两侧分别构建
  曲面网络。此探索入口依赖本机旧原型 FCStd，尚不是从干净输入 JSON 重建的
  正式 Runner。
- `tol=1e-5 mm`、`tol2=1e-10`、`max_ctrl_pts=200`。算法会重新参数化/近似曲线，
  因此显式测量与原截面的偏差；这些参数不能视为所有误差的保证上界。
- 两侧曲面加根部/尖部平面封盖，经 sewing 得到实体；未为通过验证临时放宽
  sewing 公差。静态 `Part::Feature` 保存为 FCStd，不宣称参数化依赖或无依赖
  算法重建。该交付取舍尚未定案。

本机证据位于 `output/accuracy-prototype-20260908/`：
`gordon-probe.py`、`validate-gordon.py`、`reopen.py`、`result.json`、
`validation.json`、`reopen.json`、`manifest.json`、日志及 FCStd/STEP。
manifest 保存固定源码 revision 和关键脚本/输入快照/产物 SHA-256。
本次未修改产品源码、依赖或版本，未提交 Git。

## 已完成的验证

| 项目 | 结果 |
| --- | --- |
| upper/lower 两侧曲面 | 均有效 |
| 缝合实体 | 有效、闭合、恰有一个 solid |
| FCStd 保存重开 | 静态快照仍有效、闭合、单 solid；不替代算法重建 |
| STEP | 实际 AP242 schema、mm 单位，重开有效、单 solid |
| 两侧构建及截面采样验证耗时 | 386.5 s，不含 Flatpak 启动 |
| 封盖/STEP/对照验证耗时 | 43.6 s，不含 Flatpak 启动 |

对全部 89 截面，每侧曲线各取 30 点，计算到对应 Gordon 曲面的最短距离。
最大观测保持误差：上侧 `0.000049261 mm`，下侧 `0.000455700 mm`。
这不是逐原始输入点的穷尽检查，也不是连续曲线误差上界。

前/后缘参考曲线各取 100 点，到最终实体曲面集合的最大距离分别为
`0.000179865 mm` / `0.000013995 mm`。导引约束精度应继续增加交叉参数与
边界曲线本身的检查，不能仅凭这些有限采样宣布完整保持。

## 与旧原型和 CATIA 的对照

使用原 [CATIA 候选](catia-baseline-2026-09-07.md)。曲面比较采用相同规则：
`0.1 mm` tessellation 生成候选顶点，每方向确定性抽取 400 点，计算到对方
精确裁剪曲面集合的距离。换模型后网格点集会变化，因此总体最大/RMS 不构成
完全同点的严格算法比较；固定 X 的后缘参数取点是更直接的局部对照。

| 测量 | 旧 Part::Loft | Gordon |
| --- | ---: | ---: |
| 固定 X=83 mm 后缘到 CATIA / mm | 0.571093 | 0.000336121 |
| 固定 X=81.740089 mm 后缘到 CATIA / mm | 0.511785 | 0.000412862 |
| 新模型 → CATIA 采样最大 / mm | 0.511785 | 0.194749 |
| 新模型 → CATIA 采样 RMS / mm | 0.047906 | 0.016262 |
| CATIA → 新模型采样最大 / mm | 0.329636 | 0.330448 |
| CATIA → 新模型采样 RMS / mm | 0.024723 | 0.024762 |

叶根 X=83 mm 的局部偏差缩小约 1700 倍，支持“加入前后缘约束能解决原始
叶根走向偏差”。反向曲面采样最大值并未改善，不能用叶根改善宣称整个模型
已经足够精确。Gordon 曲面本轮默认体积读数为 `1308789.42457345 mm³`；
此前已发现默认积分的数值问题，本轮不据此批准体积公差。

## 下一步与公差建议方法

1. 固定翼型切换区的同一组曲面/站位采样，区分截面保持误差、曲线对应关系和
   两种算法在截面之间选择不同曲面的设计差异。仅有离散截面不能唯一确定中间
   曲面，CATIA 对照不能自动替代领域插值规则。
2. 比较重新参数化策略、受约束曲面/其他 Gordon 实现等候选，测量连续性与
   收敛，补齐单尖、单钝、不同点数及密集翼型矩阵。
3. 给出分层误差预算：输入保持、求解/近似、STEP 往返、测量误差分别控制；
   跨后端差异单列，避免把内核差异直接解释成制造误差。
4. 以实测精度、性能和使用目的提出工程公差范围；没有用途/制造要求时保持
   未批准，不能因为现有最大误差为 0.330 mm 就把它选成允许公差。
5. 选定模型保存与算法重建契约，补齐从干净输入的重建、版本与依赖打包，才
   能考虑阶段 2 GO。当前原型保持探索状态。

补充固定点对照：原 CATIA 反向极值点
`(475.410469976,-29.170907007,11.696623576) mm` 到新 Gordon 实体曲面的距离为
`0.330448318 mm`，旧 Loft 为 `0.329635634 mm`。这确认剩余差异位于第二个
翼型切换区，且不是两次网格取点改变导致的统计假象。

2026-09-09 后续固定截面扫描在同一 X 的不同弦向位置找到约
`0.381777 mm` 的完整曲面距离，说明上述 400 点结果低估了已观察到的峰值；
输入截面、导引、同弧长对应与截面间曲面选择的分解见
[切换区固定采样诊断](gordon-transition-analysis-2026-09-09.md)。本记录保留当日
原始有限采样结果，不用后续数字改写历史证据。
