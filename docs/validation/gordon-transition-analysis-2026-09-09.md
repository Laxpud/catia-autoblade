# Gordon 翼型切换区固定采样诊断（2026-09-09）

结论：剩余跨后端差异主要发生在输入截面之间的曲线位置，而不是输入截面保持
失败，也不能主要解释为同一截面上的参数对应偏移。两个翼型切换区的固定站位
扫描分别观察到约 `0.202306 mm` 和 `0.385666 mm` 的双向截面差异；后一极值点
到对方完整三维曲面的距离仍约 `0.381777 mm`，因此不是固定 X 平面约束制造的
假象。阶段 2 仍未 GO，CATIA 候选也未获批准为黄金真值。

本记录续接 [Gordon 原型实测](gordon-prototype-2026-09-08.md)。用户尚无工程
公差，以下数值只表示实测几何差异、采样收敛或诊断参考，不是制造公差或验收
批准。

## 方法与证据

- 环境仍为 Flatpak FreeCAD 1.1.3；最终探针使用独立 user/system 配置，未修改
  用户 FreeCAD 设置。输入模型、Gordon 实体和 CATIA STEP 沿用前序记录。
- 在 `airfoil1→airfoil2` 的 `307.801818–357.909091 mm` 和
  `airfoil2→airfoil3` 的 `443.807273–486.756364 mm` 区间内，以 5% 展向间隔
  取 19 个内部站位；第二段另加入旧反向极值的精确 X，共 39 个固定站位。
- 每个站位的 Gordon 和 CATIA 切面均形成一个闭合连通 wire。Gordon 切面为
  2 条拓扑边，CATIA 切面为 5 条；比较先按共享端点连接，不依赖边编号。
- 使用源模型的 LeadingEdge 和 TrailingEdgeUpper 导引定位 LE/TE，把两侧统一为
  TE→LE，并各按弧长取 101 点。最短距离投影到对方精确裁剪截面边；同弧长距离
  则显式比较对应位置，两者分开记录。
- 另建立“同弧长点线性展向插值、再仿射修正到真实 LE/TE 导引”的参考曲线。
  它只用于暴露候选曲面的展向选择，不是已批准的领域插值规则或几何真值。
- 对两个固定峰值再用最大采样步长 `0.2/0.1/0.05/0.025 mm` 独立扫描，并把
  截面极值点投影到完整三维对方曲面，检查采样与固定平面效应。

本机忽略目录 `output/accuracy-prototype-20260908/` 保存最终
`analyze-transition-correspondence.py`、`transition-correspondence.json`、
`validate-transition-extrema.py`、`transition-extrema-validation.json` 及初始拓扑
探针。`manifest.json` 记录脚本、结果、模型和固定 CurvesWB revision 的 SHA-256。
这些探索产物没有进入 wheel，也没有修改产品源码或依赖。

## 输入截面与导引保持

四个切换边界的权威 Sketch 各侧取 51 点，向候选完整曲面测量：

| 输入截面 X / mm | Gordon 最大 / mm | CATIA 最大 / mm |
| ---: | ---: | ---: |
| 307.801818 | 0.000445912 | 0.001362321 |
| 357.909091 | 0.000039332 | 0.000157809 |
| 443.807273 | 0.000036247 | 0.000145687 |
| 486.756364 | 0.000089817 | 0.001306551 |

固定站位中，源导引锚点到候选精确截面 wire 的最大距离为：

| 区间 | Gordon LE / TE / mm | CATIA LE / TE / mm |
| --- | ---: | ---: |
| airfoil1→airfoil2 | 0.000142385 / 0.000012231 | 0.004260579 / 0.000039104 |
| airfoil2→airfoil3 | 0.000007194 / 0.000012419 | 0.000679297 / 0.001159213 |

这些有限采样表明边界截面和导引保持误差比内部曲面差异至少小约 47 倍，但不
构成连续导引误差上界。CATIA 的局部导引距离也不为零，不能把“使用了 Guide”
等同于数学精确插值。

## 固定站位差异与收敛

| 区间峰值 | X / mm | 双向截面最大 / mm | 峰值点到完整曲面 / mm | 同弧长最大 / mm |
| --- | ---: | ---: | ---: | ---: |
| airfoil1→airfoil2（75%） | 345.382273 | 0.202306 | 0.201903 | 0.206534 |
| airfoil2→airfoil3（73.583%） | 475.410470 | 0.385666 | 0.381777 | 0.393867 |

`0.025 mm` 最大步长相对 `0.05 mm` 的双向截面最大值变化不超过
`0.0000053 mm`（第一段）和 `0.0000008 mm`（第二段）。这支持当前峰值对本次
离散密度已收敛，但仍不是连续截面或整个曲面的数学最大距离证明。

在第二段峰值站位，101 点/侧结果的双向最短距离 RMS 约
`0.1960 mm`，显式同弧长对应 RMS 为 `0.2028 mm`；最大值分别约
`0.3857 mm` 和 `0.3939 mm`。同弧长对应会增加差异，但增量远小于已有最短
几何距离，因此不能把剩余偏差主要归因于截面参数域或点对应错位。

原 400 点全表面抽样的 CATIA 反向极值点在同一 X 上，到 Gordon 完整曲面的
距离仍为 `0.330448 mm`；新固定截面扫描在不同弦向位置找到约
`0.381777 mm` 的三维曲面距离。这说明旧值低估了已观察到的峰值，而不是模型
在本轮发生变化。

沿两个大间隔的误差不是单峰线性变化：两段都在约 25% 和 70%–75% 附近形成
较大峰值，在 50% 附近分别降到约 `0.0197 mm` 和 `0.0379 mm`。这种重复的
展向起伏与“候选算法使用了不同的截面间基函数、边界条件或截面影响分配”一致，
不支持把问题归为某一个输入截面局部拟合失败。

## 对应规则诊断的边界

在真实 LE/TE 锚定的线性对应参考下，第一段峰值处参考曲线到 Gordon/CATIA
截面的最大距离分别约 `0.1924/0.3946 mm`，第二段约
`0.3704/0.7561 mm`。Gordon 在此特定参考下更接近，但参考本身既不是工程规范，
也没有证明 CATIA 或 Gordon 谁代表目标叶片；这些数值只能证明“相同离散截面
与导引仍不足以唯一决定中间曲面”。

当前分解可以排除两个过强解释：输入截面保持误差不足以解释约 `0.382 mm` 的
峰值；同弧长参数对应差也只占较小增量。剩余差异应作为**截面间曲面选择差异**
处理，不能通过提高采样密度、放宽公差或宣布 CATIA 为绝对真值来关闭。

## 下一步

   和连续性目标；用可解析合成案例验证实现，而不是继续拟合 CATIA 黑盒行为。
2. 在 Gordon 参数化与至少一个受约束曲面/自定义候选上测量一阶、二阶连续性和
   曲率起伏，并用相同固定站位报告输入保持、导引保持与曲面差异。
3. 依据叶片用途和后续制造/分析要求提出工程公差；CATIA 候选是否升级为黄金
   基线仍需用户或工程责任人单独批准。
