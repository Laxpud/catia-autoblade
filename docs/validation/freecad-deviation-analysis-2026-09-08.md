## 排除采样与距离计算假象

`analyze-deviation.py` 重复原 400 点采样，保留极值坐标，并逐面检查投影。
FreeCAD → CATIA 的原极值点为模型坐标（mm）：

```text
P = (81.74008911797031, -60.75448590908558, -43.67385508443805)
Q = (81.57874201099219, -60.99928969466839, -43.25437623937038)
```

- P 到自身 FreeCAD 曲面距离：`7.105e-15 mm`。
- P 到 CATIA 全部裁剪曲面集合距离：`0.511785388444409 mm`。
- 逐面最短距离与 `Surface.parameter(P)` / `Surface.value(u,v)` 直接投影
  相互吻合：`0.511785388444421 mm`，投影点确实位于裁剪面内。
- 两方向排名前五的偏差点均贴合自身曲面，直接投影与最短距离结果相符。

这些独立检查排除了该极值的“网格顶点不在曲面上”和明显的最短距离漏解。
两种方法仍使用同一 OCC 内核，不宣称具有数学上的全局最短距离证明。

`probe-loft.py` 又脱离三角网格，直接在原生 Loft 后缘曲线上按 X 坐标求参数、
取精确曲线点，复现同一极值并发现更大的值：

| 展向 X / mm | 后缘点到 CATIA 曲面的距离 / mm |
| ---: | ---: |
| 78.740000（第 1 截面） | 约 0 |
| 79.500000 | 0.160861 |
| 80.500000 | 0.344653 |
| 81.740089 | 0.511785 |
| 83.000000 | 0.571093 |
| 84.000000 | 0.480425 |
| 85.898182（第 2 截面） | 0.000025629 |

这是一段真实的“端点吻合、中间曲线走向不同”。`0.1 mm` 网格 deflection
控制候选点生成，不会把精确顶点到 BREP 曲面的距离人为增加 `0.1 mm`。
采样数量和分布会影响能否发现峰值；原 RMS 也只是顶点计权，不是面积加权。

## 主要原因：Loft 约束与展向插值不同

实际源码和原生对象显示：

- CATIA 在 `builder.py` 的 `create_blade_surface` 中用 `AddSectionToLoft`
  加入截面，并用 `AddGuide` 加入真实前缘、上后缘及适用时的下后缘导引。
- FreeCAD 原型使用 `Part::Loft`，`Solid=True`、`Ruled=False`、
  `MaxDegree=5`。它只链接 Sketch 截面；前后缘 `ReferenceOnly` 曲线不驱动 Loft。
- 截面样条也存在实现差异：CATIA 以整条样条及实际前缘定位，FreeCAD 在离散前缘
  分为 upper/lower 插值 B-spline。但已有代表站位闭合截面差异主要为
  `0.0001–0.003 mm` 量级，解释不了本次 `0.571 mm` 的叶根截面间峰值。

关键控制证据：在 `X=81.740089 mm`，用同一组变换后的后缘输入点生成的
FreeCAD 冻结参考样条，到 CATIA 曲面的距离仅 `0.000413 mm`，到 FreeCAD Loft
曲面的距离却为 `0.351078 mm`。Loft 后缘本身则到 CATIA 偏离 `0.511785 mm`。
因此相同输入并没有强迫无导引 Loft 在截面之间跟随该参考轨迹。

这支持将主要问题定位到 **截面间展向插值、边界约束和对应关系**。目前未做
“仅移除 CATIA Guide、其他条件完全相同”的对照，不能把全部偏差定量归于
Guide 一个变量；内核参数化、端部条件、截面对应关系的贡献仍需拆分。

## 次要高差异区域：翼型切换的大间隔

原采样的其他高差异点包括：

- FreeCAD → CATIA：`X=477.207 mm`，约 `0.362315 mm`；
- FreeCAD → CATIA：`X=453.358 mm`，约 `0.287452 mm`；
- CATIA → FreeCAD：`X=475.410 mm`，约 `0.329636 mm`。

输入在两个翼型切换处的截面间隔为：

| 区间 / mm | 间隔 / mm |
| --- | ---: |
| 307.801818 → 357.909091 | 50.107273 |
| 443.807273 → 486.756364 | 42.949091 |
| 叶根普通相邻截面 | 7.158182 |

大间隔叠加翼型变化，使不同 Loft 的中间曲面选择更容易出现差异。空间分布与
此解释一致，但这不是通过补截面、重采样或移动输入消除偏差的授权。

## 阶数实验与结论边界

`probe-degree.py` 每个实验重新打开原 FCStd，仅赋值 `MaxDegree=5/3/8` 并重算，
不保存模型。3 阶改变了后缘走向；5、8 阶得到接近原曲线的结果。但这组显式
属性赋值后的重建结果均未通过 `isValid()`，因此不能作为有效修复或新的基线。
原始不赋值的重开重算模型及原 STEP 在此前检查中均有效。这个区别还需要单独
诊断，不能据本实验声称改阶数可修复偏差或已保证属性修改后的模型有效。

阶段 2 仍未 GO。下一步应以固定叶根极值点和闭合截面建立回归，拆分原生 Loft
端部/展向参数化与 Guide 约束的影响，并提高切换区的曲面采样覆盖。不能通过
放宽公差或只增加采样点来“修复”真实曲面差异。
